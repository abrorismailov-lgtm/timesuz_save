# 📥 Telegram-бот для скачивания видео и фото

Бот скачивает видео и фото из **Instagram, TikTok, X (Twitter) и YouTube Shorts**.
Для использования требуется подписка на канал [@times_officialuz](https://t.me/times_officialuz).

## Файлы проекта

| Файл | Зачем нужен |
|---|---|
| `main.py` | весь код бота |
| `requirements.txt` | список библиотек Python |
| `Procfile` | говорит Railway, как запускать бота |
| `nixpacks.toml` | устанавливает ffmpeg на сервере |

# 🚀 Инструкция по деплою (для чайника)

## Шаг 1. Создаём бота в Telegram

1. Открой Telegram и найди **@BotFather**.
2. Отправь ему команду `/newbot`.
3. Придумай имя бота (например, `Times Video Saver`).
4. Придумай username бота — он должен заканчиваться на `bot` (например, `times_saver_bot`).
5. BotFather пришлёт **токен** вида `1234567890:AAEhBOweik6ad...` — **скопируй и никому не показывай!**

## Шаг 2. Делаем бота админом канала (ОБЯЗАТЕЛЬНО!)

Чтобы бот мог проверять подписку, он должен быть администратором канала:

1. Зайди в канал **@times_officialuz** (ты должен быть его владельцем/админом).
2. Настройки канала → **Администраторы** → **Добавить администратора**.
3. Найди своего бота по username и добавь его.
4. Права можно оставить минимальные — главное, чтобы бот был в списке админов.

⚠️ Без этого шага проверка подписки работать НЕ будет!

## Шаг 3. Загружаем код на GitHub

1. Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта).
2. Нажми **+** в правом верхнем углу → **New repository**.
3. Название: `tg-saver-bot`. Выбери **Private** (чтобы код не был публичным). Нажми **Create repository**.
4. На странице репозитория нажми **uploading an existing file** (или кнопку **Add file → Upload files**).
5. Перетащи туда все файлы проекта: `main.py`, `requirements.txt`, `Procfile`, `nixpacks.toml`, `.gitignore`.
6. Внизу нажми зелёную кнопку **Commit changes**.

## Шаг 4. Деплой на Railway

1. Зайди на [railway.com](https://railway.com) и нажми **Login** → войди через **GitHub**.
2. Нажми **New Project** → **Deploy from GitHub repo**.
3. Railway попросит доступ к репозиториям — разреши доступ к `tg-saver-bot`.
4. Выбери репозиторий `tg-saver-bot` — начнётся сборка.

## Шаг 5. Добавляем токен бота

1. В проекте Railway кликни на свой сервис (карточка с названием репозитория).
2. Открой вкладку **Variables**.
3. Нажми **New Variable** и добавь:
   - **Name:** `BOT_TOKEN`
   - **Value:** токен из BotFather (из Шага 1)
4. Нажми **Add** — Railway автоматически перезапустит бота.

## Шаг 6. Проверяем, что всё работает

1. В Railway открой вкладку **Deployments** → кликни на последний деплой → **View Logs**.
2. Если видишь строку `Бот запущен!` — всё отлично! ✅
3. Открой своего бота в Telegram, нажми `/start` и отправь ссылку на видео из TikTok.

## ❓ Частые проблемы

**Бот не отвечает** → проверь логи в Railway. Чаще всего неправильно вставлен токен в Variables.

**«Не удалось проверить подписку»** → бот не добавлен админом в канал (Шаг 2).

**Instagram не скачивается** → Instagram часто блокирует серверные IP. Приватные посты скачать нельзя. Публичные Reels обычно работают.

**Видео не отправляется** → Telegram Bot API не позволяет ботам отправлять файлы больше 50 МБ.

**Railway просит оплату** → у Railway есть пробный период с бесплатным кредитом (~$5). Дальше хостинг платный — от ~$5/мес. Актуальные условия смотри на railway.com/pricing.

## 🔄 Как обновить бота

Просто измени файл в GitHub (открой файл → иконка карандаша → внеси правки → Commit changes). Railway сам подхватит изменения и перезапустит бота.
